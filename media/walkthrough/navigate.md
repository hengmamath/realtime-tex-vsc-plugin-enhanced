# Source ↔ preview

| Action | Result |
|---|---|
| **Double-click a word in the source** | Reveal and highlight its preview line (the default). |
| **◎ ▾** menu (**Source to preview**) | Choose **Single click**, **Double click**, or **Off**. Keyboard movement and typing leave the preview in place. |
| **Cmd+Alt+J** | Jump the preview to the cursor and highlight the spot. |
| **Double-click** (or Ctrl/Cmd+click) in the preview | Jump to that paragraph in the source. |
| Click a formula reference | Jump to its destination. Use **← / →** in the toolbar or **Cmd+[** / **Cmd+]** to move through reading history. |
| Click the page counter, such as **28 / 49** | Enter a page number and press **Enter** or **Go** to jump there. |
| **Document outline** in the toolbar | Open the compiled chapter and section tree. Click a heading to jump; use **← / →** to return. Resize the sidebar or fold branches; the current section is highlighted. In a narrow panel, it opens over the page and closes after a jump. |
| **Ctrl + mouse wheel**, **Ctrl + = / −** | Zoom the preview. **Fit width** fits the page to the panel. |
| **↻** | Recompile the whole document to refresh references and page layout, keeping the engine running. |
| **⋯** | **Restart engine** for recovery, **Open LaTeX log**, or **Choose main file…**. |
