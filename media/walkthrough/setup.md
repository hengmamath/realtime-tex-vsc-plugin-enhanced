# What Realtime TeX Enhanced needs

| Item | Requirement |
|---|---|
| Computer | Apple Silicon Mac (M series). |
| LuaLaTeX | TeX Live 2026+ recommended; local regression coverage also includes TeX Live 2025. Install the packages used by your document. |
| Live engine | Included in this VSIX, together with its matching support files. No separate rtex download or Rust installation needed. |

Disable the original Realtime TeX extension before enabling this enhanced fork. **Check Setup** checks the bundled engine and helps locate LuaLaTeX.
